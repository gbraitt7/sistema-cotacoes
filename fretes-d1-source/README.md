# Fonte de referência — fretes com D1

Esta pasta registra arquivos selecionados da versão publicada do aQuaLog.

O sistema em produção está em https://gestao-fretes-v4.giovanni-fagundes.chatgpt.site e usa a infraestrutura Cloudflare já configurada, incluindo D1 e autenticação da plataforma. Este recorte no GitHub **não é um pacote autônomo de implantação**: arquivos de autenticação, políticas de acesso, dados de demonstração e configuração protegida não foram copiados para o repositório público.

A página principal do GitHub redireciona para o sistema compartilhado. A versão anterior baseada em armazenamento local foi preservada em `legacy-localstorage.html`.
