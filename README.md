# aQuaLog — Gestão de Fretes

A página do projeto encaminha para o sistema de fretes compartilhado, conectado ao Cloudflare D1:

https://gestao-fretes-v4.giovanni-fagundes.chatgpt.site

A versão anterior, baseada em armazenamento local do navegador, está preservada em [legacy-localstorage.html](./legacy-localstorage.html). Arquivos de referência da integração estão em [fretes-d1-source](./fretes-d1-source/README.md). Esse recorte não é um pacote independente de implantação; a autenticação e os recursos protegidos permanecem configurados no ambiente do sistema publicado.
